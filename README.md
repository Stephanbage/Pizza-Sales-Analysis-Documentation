🍕 Pizza Sales Analysis

A data-driven project analyzing pizza sales to uncover customer preferences, revenue trends, and ordering patterns. Insights help optimize inventory, pricing, and marketing strategies for a pizzeria business.

🔍 Key Features:
✅ Total sales & revenue analysis
✅ Top-selling pizzas & sizes
✅ Order trends by time & category
✅ Revenue contribution insights

📊 Tech Used: SQL, Data Analysis, Google Sheets

🚀 Optimizing sales with data-driven decisions!
